# Lab 02: Image Metadata Analyzer

Inspect image dimensions, format, color mode, DPI, transparency, file size, and
EXIF metadata with Pillow. Supported inputs include JPEG, PNG, GIF, BMP, TIFF,
WebP, and PPM.

Install dependencies from the repository root:

```powershell
python -m pip install -r Capstone-Projects/Consolidated-Multimedia-Analyzer/requirements.txt
```

Run this lab from the repository root:

```powershell
python Cluster02-Image-Processing/Lab02-Image-Metadata-Analyzer/image.py Cluster02-Image-Processing/Lab02-Image-Metadata-Analyzer/samples/sample.ppm --json
```

The unified analyzer is available in `Capstone-Projects/Consolidated-Multimedia-Analyzer/`.
