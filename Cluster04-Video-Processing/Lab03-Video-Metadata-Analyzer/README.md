# Lab 03: Video Metadata Analyzer

Inspect container, duration, bitrate, stream codecs, resolution, frame rate,
pixel format, and tags with FFprobe.

Install FFmpeg and make sure `ffprobe` is available on `PATH`. Run this lab
from the repository root:

```powershell
python Cluster04-Video-Processing/Lab03-Video-Metadata-Analyzer/video.py path/to/movie.mp4 --json
```

Sample-folder guidance is in `samples/README.md`; media files are not committed.
